# Materials for the Web

There are so many materials out in the world, that we don't often have on the web. Like Wood – its been a essential historical material that our civilization utilized for architecture, furniture, ornaments, tools, and even early automobiles. The internet online compared to that feels so plain. I understand the disadvantages of skeuomorphism, that its not very efficient in conveying interactions, but I believe there's a balance to be achieved here.

This is an attempt to make to add more character to the web, via expressive materials, brought from our real word to the digital.
